# DF Studio — public documents

Policies and notices that have to be reachable on the open web, because an app
store will not publish without a link to them.

Served by GitHub Pages. Each app has a folder, and each folder's `index.html`
is the page the store is given.

| App | Document | Address |
| --- | --- | --- |
| Fart Box | Privacy policy | `fart-box/` |

The markdown beside each page is the same text, kept for reading and editing.
The page is what the store sees.
